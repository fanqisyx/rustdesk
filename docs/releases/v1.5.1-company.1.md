# RustDesk 公司设备管理版 v1.5.1-company.1（预发布）

基于 RustDesk 1.5.1，增加独立自建账号、设备目录与集中授权服务。此为首次公司版预发布，原生客户端仍需要完整构建与双机实机验收。

## 本版功能

- 客户端自行注册公司账号，注册成功后自动登录；新账号默认没有设备权限。
- 内部固定资产与外部客户设备树形分组，记录设备名称、资产编号、责任人、地点和系统。
- 管理员按员工、分组授权目录查看、桌面、文件传输、终端、隧道、摄像头及允许分享，支持到期和撤销。
- 将单台已登记设备分享给同一服务上的其他账号，可选择权限与有效期；普通成员须有直接转授权，分享不会传递继续转发的权限。
- 被控端通过短时一次性票据核验账号及设备权限，保留设备密码、2FA 或人工确认。
- 管理网页、操作审计、自建 Linux/Docker Compose 部署及 v1 → v2 数据库升级。

## 发布文件

- `rustdesk-management-v1.5.1-company.1.zip`：管理服务源码、部署配置、说明和测试；解压后进入 `management/` 使用。
- `rustdesk-source-v1.5.1-company.1.zip`：当前提交的完整项目源码，包含固定版本的 `libs/hbb_common` 子模块，可用于原生客户端构建。
- `release-manifest.json`：提交与子模块版本信息。
- `SHA256SUMS`：上述发布文件校验值。
- 各平台原生客户端安装包仅在对应 GitHub CI 构建成功后加入附件。管理服务 ZIP 不包含桌面客户端。

发行标签为 `v1.5.1-company.1`，客户端基础版本与二进制文件名沿用上游 `1.5.1`；管理 API 版本为 `0.1.0`，数据库 schema 为 `2`。

公司版原生发布构建设置 `RUSTDESK_ENTERPRISE_REQUIRED=1`，缺少有效公司服务器配置或设备凭据时拒绝接入受管端。部署时仍需逐台配置自己的 HTTPS 管理地址和设备独立凭据。hbbs/hbbr 继续单独部署。

## 验证与限制

本地已通过 18 项 Python 服务端集成测试、4 项独立 Dart 请求模块测试、网页注册／分组／分享流程，以及隔离 Rust 授权模块与真实管理 API 联调。完整结果和验证范围见 `management/VALIDATION.md`；网页与请求模块测试不代表完整 Flutter 客户端实机验收。

- 完整原生客户端构建以本标签对应 CI 结果为准；尚未完成双机远控验收。
- 分享撤销、到期及权限收回阻止后续连接，不立即断开已建立会话。
- `view` 是目录查看权限，不是远程画面只读；桌面会话内的剪贴板等仍使用被控端本地策略。
- RustDesk Web 远控引擎暂不支持本版票据，Sciter 账号界面没有重做。
- 默认开放自助注册，注册不自动纳管本机或授予设备权限。可用 `RDM_ALLOW_REGISTRATION=0` 关闭新注册。

升级前停止管理服务并备份完整数据库卷。v1 数据库会新增分享表并升级至 v2；回退旧版需恢复升级前备份。
